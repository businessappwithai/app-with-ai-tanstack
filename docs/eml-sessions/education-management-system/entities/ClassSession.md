# ClassSession  ·  standalone  ·  category: Academics

**Role.** One dated, timed meeting of a section. The register is taken against this and nothing else.

**Placement.** Standalone — argued at Gate B and recorded there. *Today's sessions across every section* is the register screen, which is the most-opened list in the application; a session is identified by its own date and time, not by its position in a section.

## Fields

| Column | Type | Modifiers | Purpose |
|---|---|---|---|
| `id` | string | PK | The record's own identifier. Generated by the application and never keyed; it is never shown as a display value. |
| `class_section_id` | string | FK | The group meeting. A session belongs to exactly one section, which is what makes attendance attributable to a teacher. |
| `room_id` | string | FK OPTIONAL | Where this one meeting happens. Blank means the section's usual room; set only for a one-off move, which is why the register prints it. |
| `staff_id` | string | FK OPTIONAL | Who is actually taking this meeting. Blank means the section's own teacher; set for cover, and the cover report is built from exactly this field being non-blank. |
| `starts_at` | datetime | — | When the meeting begins, in school local time. The register is expected within the first fifteen minutes of it, and the late-register report measures from here. |
| `ends_at` | datetime | — | When the meeting finishes. Derived from the course's taught hours at scheduling time and held rather than recomputed, so a later curriculum change cannot move a session already taught. |
| `status` | string | — | scheduled — will run, register not yet taken; held — it happened and the register is closed; cancelled — it did not run, and no attendance marks are expected against it. |
| `register_taken` | boolean | — | Set when the teacher closes the register. It is the field the statutory return counts against, because a session with no register is a hole in the return rather than a day nobody was absent. |
| `topic` | string | OPTIONAL | What was taught, in a line. Optional, and the only place a family looking at a missed session can see what their child missed. |
| `cancellation_reason` | text | OPTIONAL | Why the meeting did not run — snow, cover unavailable, examination clash. Read by the attendance officer when explaining a gap in a student's record. |

## Cross-entity effects

Closing a register updates each enrolment's attendance rate — that is written by the `AttendanceRecord` hooks, one mark at a time, rather than by the session.

## Open questions

Whether a cancelled session should generate excused marks for the group, so the statutory return has a row per student. Not modelled: `register_taken` staying false on a cancelled session is the honest record, and `teacher-registers-not-taken` excludes cancelled sessions for exactly that reason.
