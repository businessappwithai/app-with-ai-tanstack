# AttendanceRecord  ·  child of ClassSession

**Role.** One student's mark for one session. The statutory attendance return is built from these, which is why an absence must say whether it was authorised.

**Placement.** Child of `ClassSession` — the register is a tab on the session, and a mark away from its session means nothing.

## Fields

| Column | Type | Modifiers | Purpose |
|---|---|---|---|
| `id` | string | PK | The record's own identifier. Generated by the application and never keyed; it is never shown as a display value. |
| `class_session_id` | string | FK | The meeting being registered. This is the link back to the parent record, so the register appears as a tab on the session rather than a screen of its own. |
| `student_id` | string | FK | The student being marked. One mark per student per session; a second is a correction and replaces the first. |
| `marked_by_id` | string | FK | The member of staff who took the register and is accountable for the mark. Named marked_by_id so it resolves to the Staff table; a cover teacher's name here is how a disputed mark is traced. |
| `status` | string | — | present — in the room; late — arrived after the register, and minutes_late says how late; absent — not there, and is_authorised decides whether it counts against the statutory return; excused — off site on school business, which is not an absence at all. |
| `minutes_late` | integer | OPTIONAL | How late the student arrived. Only meaningful with a late mark, and the persistent-lateness report is built from the sum of it rather than the count of marks. |
| `is_authorised` | boolean | — | Whether the school accepted the reason for the absence. This single boolean is the statutory distinction the whole return turns on, and it is deliberately separate from the mark so that an absence can be re-authorised later without rewriting the register. |
| `absence_reason` | text | OPTIONAL | Why the student was not there, in the guardian's words where they gave them. Required for an authorised absence and for an excused mark — an unexplained authorisation is the one the inspector asks about. |
| `marked_at` | datetime | — | When the mark was entered, not when the session ran. A register closed two days late is a compliance finding, and this is the field that shows it. |

## Enums

- `status` → **AttendanceMark**: present, late, absent, excused

## Relationships

- `Student ||--o{ AttendanceRecord` — marked in *(this side carries the foreign key)*
- `ClassSession ||--o{ AttendanceRecord` — registers *(this side carries the foreign key)*
- `Staff ||--o{ AttendanceRecord` — marked by *(this side carries the foreign key)*

**Indexes.** `AttendanceRecord(class_session_id, status)` · `AttendanceRecord(student_id, status)`

## Lifecycle

None, deliberately. `present`, `late`, `absent` and `excused` are classifications rather than stages: a mark is corrected, not advanced, and drawing a machine over them would refuse a correction with a 403. `is_authorised` is kept separate from the mark for the same reason — an absence can be re-authorised later without rewriting the register.

## Rules

### `attendanceMarking` on `beforeCreate` — **`%%action` decision table — it can act**

- `requireAuthorisedAbsenceReason validation-error when: status == "absent" and is_authorised == true and absence_reason == null message: An authorised absence needs the reason the school accepted — it is what the inspector asks about.`
- `requireExcusedReason validation-error when: status == "excused" and absence_reason == null message: An excused mark needs to say what the student was doing instead.`
- `requireMinutesLate validation-error when: status == "late" and minutes_late == null message: A late mark needs the minutes — the persistent-lateness report sums them.`
- `clearAuthorisationWhenPresent transform when: status == "present" field: is_authorised value: false`

## Hooks

## Cross-entity effects

Each mark updates the enrolment's `attendance_rate` (`updateEnrolmentAttendanceRate` on create, `correctEnrolmentAttendanceRate` on a correction), which is the number the pastoral team sorts by and the statutory floor is measured against.
