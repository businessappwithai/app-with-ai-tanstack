# Course  ·  standalone  ·  category: Academics

**Role.** A subject as it is offered and examined. Distinct from the taught groups it is scheduled as, which are sections.

**Placement.** Standalone. The curriculum list is a screen the whole school uses.

## Fields

| Column | Type | Modifiers | Purpose |
|---|---|---|---|
| `id` | string | PK | The record's own identifier. Generated by the application and never keyed; it is never shown as a display value. |
| `code` | string | UK | The examination code the subject is known by, e.g. MATH-H. Unique and stable across terms, because results are reported against it for years afterwards. |
| `name` | string | — | The subject as families see it on a report card, e.g. "Mathematics (Higher)". |
| `department_id` | string | FK | The department that owns the course, sets its marking policy and is accountable for its results. |
| `level` | string | — | foundation — supported entry; core — the standard offer; higher — extended content; advanced — final-year specialism with an entry requirement. The level decides which year groups may be enrolled and appears on the transcript. |
| `credit_hours` | integer | — | Taught hours per week. The timetable is built from this, and a change here does not move sections already scheduled. |
| `is_active` | boolean | — | Cleared when a subject is withdrawn from the curriculum. Past sections and results survive; no new section can be scheduled against it. |

## Enums

- `level` → **CourseLevel**: foundation, core, higher, advanced

## Relationships

- `Department ||--o{ Course` — offers *(this side carries the foreign key)*

## Cross-entity effects

None. Retiring a course does not touch its sections: past teaching and past results must survive it.
