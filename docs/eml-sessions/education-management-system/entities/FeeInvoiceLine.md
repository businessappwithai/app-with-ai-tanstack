# FeeInvoiceLine  ·  child of FeeInvoice

**Role.** One charge on an invoice — tuition, transport, examination entry or materials. Priced when the line is written and never repriced afterwards.

**Placement.** Child of `FeeInvoice`. The noun is the tell.

## Fields

| Column | Type | Modifiers | Purpose |
|---|---|---|---|
| `id` | string | PK | The record's own identifier. Generated by the application and never keyed; it is never shown as a display value. |
| `fee_invoice_id` | string | FK | The invoice this charge belongs to. This is the link back to the parent record, so lines appear as a tab on the invoice. |
| `charge_type` | string | — | tuition — the termly fee for the place; transport — the school bus; examination_entry — board fees, which are not refundable once entered; materials — laboratory and art consumables; activity — trips and clubs; late_fee — added by the finance office and always explained in the description. |
| `description` | string | — | What the charge is for, in the words the guardian will read on the statement. "Chemistry practical materials — Autumn" rather than "materials". |
| `quantity` | integer | — | How many of the charge. One for a termly fee; several for trips or repeated items, and the line total is checked against it. |
| `unit_amount` | decimal | — | The price of one, gross, as it stood when the line was written. Never repriced afterwards — a fee increase applies to the next term's invoice, not to a line already raised. |
| `line_total` | decimal | — | Quantity times unit amount, held rather than computed so that a rounding decision made once is the number the guardian sees on every statement. |

## Cross-entity effects

Every write recalculates the invoice's total — `addLineToInvoiceTotal`, `recalculateInvoiceTotal` and `removeLineFromInvoiceTotal`, one per event, because a handler name is a function name in the generated per-entity module and the compiler keeps only the first binding of a name that serves two events. `priceLine` computes `line_total` from quantity and unit amount at creation, so a rounding decision is made once and shown identically on every statement afterwards.

## Open questions

Tax. The school's fees are not taxed in the modelled jurisdiction, so no tax column exists — a school where they are would need one per line rather than one per invoice.
