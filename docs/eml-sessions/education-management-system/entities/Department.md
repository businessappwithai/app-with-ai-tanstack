# Department  ·  standalone  ·  category: Academics

**Role.** A teaching department that owns a group of courses and employs the staff who teach them. Reference data, created once when the school's structure is set up.

**Placement.** Standalone. A list of departments away from any owner is the school's own structure screen; nothing owns a department.

## Fields

| Column | Type | Modifiers | Purpose |
|---|---|---|---|
| `id` | string | PK | The record's own identifier. Generated by the application and never keyed; it is never shown as a display value. |
| `code` | string | UK | The short label used on the timetable and in reporting, e.g. SCI. Unique and stable — it is printed on every report card, so it is not renamed lightly. |
| `name` | string | — | The department as staff and families say it, e.g. "Science". Shown wherever a course is listed. |
| `staff_id` | string | FK OPTIONAL | The head of department — the member of staff accountable for its courses and its marking trail. Named staff_id rather than head_teacher_id so the reference resolves to the Staff table and renders as a person picker. |
| `is_active` | boolean | — | Cleared when a department is merged or dissolved. Its courses and history survive; no new course can be created against it. |
