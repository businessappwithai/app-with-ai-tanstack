# Room  ·  standalone  ·  category: Academics

**Role.** A teaching space with a legal capacity. A section's own capacity may be lower but is never allowed above the room's.

**Placement.** Standalone reference data. Rooms are listed, filtered and reported on in their own right.

## Fields

| Column | Type | Modifiers | Purpose |
|---|---|---|---|
| `id` | string | PK | The record's own identifier. Generated by the application and never keyed; it is never shown as a display value. |
| `code` | string | UK | The label on the door, e.g. S12. Unique, and what appears on the printed timetable a student follows. |
| `name` | string | — | The room's full name where it has one, e.g. "Physics Laboratory 2". Blank rooms are shown by code alone. |
| `building` | string | — | Which building the room is in. Used to catch timetables that move a class across the site in a five-minute gap. |
| `capacity` | integer | — | The maximum number of people the room legally holds. A section's own capacity is seeded from this and may be lower, never higher. |
| `is_active` | boolean | — | Cleared while a room is out of use for refurbishment. Past sessions survive; the timetable will not schedule into it. |

## Cross-entity effects

None. A room's capacity seeds a section's capacity at timetabling, and that copy is deliberate: a room re-measured next year must not change a section already recruited to.
