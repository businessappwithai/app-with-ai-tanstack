Model viewer

A model is a Mermaid document, and Mermaid draws only the ERD half of it. The rules, the workflows, the enums and the access control live in %% directives it treats as comments — which is the half worth checking while the model is still being written. This page draws all of it, using the parser and compilers this repository generates applications with, so what you see is what the generator read.
